# Values Card

`@edv4h/croupier-plugin-values-card` implements the Wevox Values Card game for team building.

## Installation

```bash
pnpm add @edv4h/croupier-plugin-values-card
```

## Usage

```typescript
import { CroupierCore } from "@edv4h/croupier-core";
import { createValuesCardConfig } from "@edv4h/croupier-plugin-values-card";

const game = new CroupierCore(
  createValuesCardConfig({ theme: "チームで大事にしたいこと" }),
  ["alice", "bob", "charlie"],
);
```

### Options

| Option | Default | Description |
|--------|---------|-------------|
| `theme` | `"人生で大事な5つの価値観"` | Theme decided before the game (e.g. by the host). Included in the result. |
| `cards` | `DEFAULT_VALUES_CARDS` | Card master. Any `{ id: string \| number }` objects; extra attributes (image, effect type, ...) are kept as-is. |
| `endRule` | `"deckEmpty"` | `"deckEmpty"`: ends on the discard of the turn the deck ran out. `"lastRound"`: every player gets one more turn after that. |
| `maxTurns` | — | End after this many turns (safety cap). |
| `shouldEnd` | — | `(game) => boolean` checked after each discard to add other end conditions. |
| `turnTimeoutMs` | — | Turn timeout; idle players are taken over by `bot`. |
| `bot` | `valuesCardAutoPlayStrategy` | Strategy for bots and timeout takeover. `valuesCardRandomBotStrategy` is also exported. |

Card types are generic: `createValuesCardConfig<MyCard>({ cards: master })`.

## How It Works

Players take turns drawing and discarding value cards. Each card represents a personal value (e.g., "Integrity", "Creativity", "Growth"). The goal is to build a hand of values that represent what matters most to you, sparking team discussion.

## Phases & Stages

The game has a single phase `play` with two alternating stages:

| Stage | Description |
|-------|-------------|
| `waitingForDraw` | Current player draws a card from the deck or discard pool |
| `waitingForDiscard` | Current player discards a card from their hand |

The stages cycle: draw → discard → (next player) → draw → discard → ...

## Actions

| Action | Stage | Description |
|--------|-------|-------------|
| `drawFromDeck` | waitingForDraw | Draw the top card from the deck |
| `drawFromDiscard` | waitingForDraw | Pick a card from the discard pool. Payload: `{ cardId: string \| number }` |
| `discardCard` | waitingForDiscard | Discard a card from hand. Payload: `{ cardId: string \| number }` |

## Turn Order

Sequential round-robin. Each player completes a full draw-discard cycle before play passes to the next player.

## Game End

By default (`endRule: "deckEmpty"`) the game ends as soon as the player who drew the last card from the deck discards. With `endRule: "lastRound"`, every player gets one more turn after that.

The result contains `theme`, `endReason`, `finalHands` (each player's final hand in hand order), `playerResults[pid].stats.finalHand` and `turnCount`.

## Auto-play

`valuesCardAutoPlayStrategy` (the default `bot`) is used when a player is disconnected or idle: with 5 cards it draws from the deck, then discards the card it just drew. It never draws from the discard pool while the deck has cards. If the player had already drawn before going idle, that card is discarded.

## State Masking

- Players see their own hand
- Opponent hands are hidden
- The discard pool is visible (shows card and who discarded it)
- Deck is shown as a count

## Value Cards

The default deck includes 25 value cards:

Integrity, Creativity, Growth, Empathy, Courage, Respect, Fairness, Gratitude, Resilience, Collaboration, Curiosity, Authenticity, Kindness, Accountability, Optimism, Patience, Loyalty, Humility, Passion, Wisdom, Balance, Freedom, Trust, Compassion, Innovation
