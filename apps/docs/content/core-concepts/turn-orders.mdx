# Turn Orders

Turn orders define **who can act and when**. The engine uses a strategy pattern with two methods: `first()` and `next()`.

## The TurnOrder Interface

```typescript
interface TurnOrder<S extends GameState = GameState> {
  first(ctx: CroupierContext<S>): PlayerId | PlayerId[];
  next(ctx: CroupierContext<S>): PlayerId | PlayerId[] | null;
}
```

- **`first(ctx)`** — Called when entering a phase or stage. Returns who goes first.
- **`next(ctx)`** — Called after each action. Returns the next player, or `null` to signal the turn order is complete.

Returning an **array** of player IDs means multiple players can act simultaneously.

Both methods receive the full `CroupierContext`, giving access to `ctx.game` (game state), `ctx.players` (all player IDs), `ctx.lastPlayer` (who just acted), and `ctx.actionCount`.

## Built-in Turn Orders

### ROUND_ROBIN

Players take turns one at a time, cycling through the player list.

```typescript
import { ROUND_ROBIN } from "@croupier/core";

phases: {
  play: {
    turnOrder: ROUND_ROBIN,
    // players[0] → players[1] → ... → players[n] → null (cycle complete)
  }
}
```

`next()` returns `null` after all players have acted once, signaling the end of the round.

### ALTERNATING

Two players alternate, each getting one action per turn.

```typescript
import { ALTERNATING } from "@croupier/core";

phases: {
  main: {
    turnOrder: ALTERNATING,
    // player1 acts → null (turn ends) → player2 acts → null → ...
  }
}
```

`next()` always returns `null` immediately, ending the current player's turn. The phase machine handles swapping players on re-entry.

### SIMULTANEOUS

All players can act at the same time (barrier synchronization).

```typescript
import { SIMULTANEOUS } from "@croupier/core";

phases: {
  voting: {
    turnOrder: SIMULTANEOUS,
    allowedActions: ["vote"],
    // All players can vote simultaneously
    always: [
      { target: "evaluation", guard: (ctx) => allVoted(ctx.game) },
    ],
  }
}
```

Both `first()` and `next()` return all players. Transition happens when an `always[]` guard matches.

## Custom Turn Orders

Use `custom()` for game-specific logic:

```typescript
import { custom } from "@croupier/core";

const pokerTurnOrder = custom({
  first(ctx) {
    return ctx.game.playerOrder[ctx.game.currentPlayerIndex];
  },
  next(ctx) {
    // Skip folded/all-in players
    if (isBettingRoundComplete(ctx.game)) return null;
    const nextIdx = findNextActivePlayer(ctx.game);
    return nextIdx === -1 ? null : ctx.game.playerOrder[nextIdx];
  },
});
```

## Choosing a Turn Order

| Game Type | Turn Order | Why |
|-----------|-----------|-----|
| Card games (poker) | Custom round-robin | Need to skip folded players, check bet matching |
| Board games | ROUND_ROBIN | Simple one-at-a-time |
| TCG (Hearthstone-style) | ALTERNATING | Full turn per player |
| Voting / estimation | SIMULTANEOUS | All act at once |
| Complex games | `custom()` | Full control over turn logic |
