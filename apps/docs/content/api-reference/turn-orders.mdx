# Turn Orders API

Built-in turn order strategies and the `custom()` factory.

## Imports

```typescript
import {
  ROUND_ROBIN,
  ALTERNATING,
  SIMULTANEOUS,
  custom,
} from "@edv4h/croupier-core";
```

## ROUND_ROBIN

Cycles through players in order. Returns `null` after one full cycle.

```typescript
const ROUND_ROBIN: TurnOrder
```

| Method | Behavior |
|--------|----------|
| `first(ctx)` | Returns `ctx.players[0]` |
| `next(ctx)` | Returns the next player in the list, or `null` when all have acted |

**Use for**: Card games, board games, any sequential-play game.

## ALTERNATING

Each player gets one action per turn, then play switches to the other player.

```typescript
const ALTERNATING: TurnOrder
```

| Method | Behavior |
|--------|----------|
| `first(ctx)` | Returns `ctx.players[0]` |
| `next(ctx)` | Always returns `null` (ends the current player's turn immediately) |

The phase machine handles player swapping on re-entry.

**Use for**: TCGs, chess-like games, any game with full turns per player.

## SIMULTANEOUS

All players can act at the same time.

```typescript
const SIMULTANEOUS: TurnOrder
```

| Method | Behavior |
|--------|----------|
| `first(ctx)` | Returns all `ctx.players` |
| `next(ctx)` | Returns all `ctx.players` (everyone stays active) |

Phase transitions happen via `always[]` guards, typically when all players have completed their actions.

**Use for**: Voting, simultaneous selection, real-time phases.

## custom()

Factory function for creating custom turn orders.

```typescript
function custom(order: TurnOrder): TurnOrder
```

**Example:**

```typescript
const skipInactivePlayers = custom({
  first(ctx) {
    return ctx.game.playerOrder.find(id => ctx.game.players[id].active)!;
  },
  next(ctx) {
    if (isRoundComplete(ctx.game)) return null;
    return findNextActivePlayer(ctx.game);
  },
});
```

## TurnOrder Interface

```typescript
interface TurnOrder<S extends GameState = GameState> {
  first(ctx: CroupierContext<S>): PlayerId | PlayerId[];
  next(ctx: CroupierContext<S>): PlayerId | PlayerId[] | null;
}
```

## CroupierContext

Turn orders receive the full `CroupierContext` — the same unified context used by actions, guards, and lifecycle callbacks:

```typescript
interface CroupierContext<S extends GameState = GameState> {
  game: S;                      // The game state
  players: PlayerId[];          // All player IDs
  currentPlayers: PlayerId[];   // Player(s) whose turn it is
  lastPlayer: PlayerId | null;  // Who acted last
  actionCount: number;          // Actions taken in current phase
  result: GameResult | null;    // Game result (null while playing)
  log: ActionLogEntry[];        // Complete action history
}
```

Access game state via `ctx.game`, player list via `ctx.players`, and the last player via `ctx.lastPlayer`.
